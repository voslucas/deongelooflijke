# Ongelooflijk Archief

An unofficial, searchable archive of **De Ongelooflijke Podcast** (EO / NPO Radio 1), built like an IMDb for the show: every episode, guest, theme and mentioned name, with statistics and a transcript layer.

- **Live prototype:** https://claude.ai/artifact/6P7EZ3A5XnN5hgeUbDNT94 (private until shared)
- **Design system:** https://claude.ai/artifact/LpNfxKQ6AyMareE6b1FhMf (private until shared)
- **Open locally:** `site/dist/index.html`. It is a single self-contained file: open it in any browser, no server needed.

## What's real and what's example data

| Real (from the public RSS feed, 329 items) | Example data (until transcripts exist) |
| --- | --- |
| Episode numbers, titles, dates, durations, descriptions | Speakers per sentence, timestamps, chapters |
| Guests (auto-extracted, hand-corrected), themes, formats | Speaking time, words per minute, verbal tics |
| Quotes in descriptions, “recommended episodes” links | Laughs, interruptions, energy curve, bingo |
| All statistics on the Statistics page above “Uit de transcripties” | Mentions of people, philosophers, books, places |

Example data is generated by a seeded random generator in the page, so it is stable between visits and always labelled **Voorbeelddata** in the UI. See `docs/transcript-schema.md` for how real transcripts replace it.

```
data/intermediate/      Scratch output of the build steps
scripts/                The data and build pipeline (Python 3, standard library only)
docs/                   Coding guide, transcript data contract, feature inventory
CLAUDE.md               Design and coding instructions for anyone (or any agent) changing this project
```

## Rebuild

```bash
# 1. refresh the feed (download it yourself; NPO blocks some automated clients)
#    save as data/raw/feed.xml
python scripts/1_parse_feed.py data/raw/feed.xml   # -> data/intermediate/raw.json
python scripts/2_extract_guests.py                 # -> data/intermediate/eps1.json (prints episodes with no guest found)
python scripts/3_build_episode_data.py             # -> data/episodes.json (themes, formats, quotes, bios, manual fixes)
python scripts/4_build_site.py                     # -> site/dist/index.html
```

Manual guest corrections live in `scripts/3_build_episode_data.py` (`REN`, `DROP`, `MAN`, `ADD`) and short bios in the `bios` overrides at the bottom. Update the `built` date there when you refresh.
